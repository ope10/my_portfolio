# Project screenshots

Add one screenshot or cover image for each project to this folder, using these filenames:

- `foodie-finder.jpg`
- `safe-haven.png`
- `safe-haven-business.png` (second Safe Haven screenshot)
- `kanban-dashboard.jpg`
- `construction-company.png`
- `construction-company-gallery.png`
- `construction-company-design-gallery.png`
- `cloudcard-dashboard.jpg`
- `cardholder-dashboard.png`
- `cardholder-dashboard-groups.png`
- `cardholder-dashboard-details.png`
- `student-loan-platform.jpg`

PNG and WebP work too—if you choose a different extension or filename, update the matching `image` value in `data/projects.js`.

Landscape screenshots work best. The site crops images with `object-fit: cover`, so use a wide image that shows the most important part of each project near its center.
